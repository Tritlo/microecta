# Future work
+ Generate from arbitrary ECTAs with direct counting and unranking of finite equality-constrained automata, eventually extending that boundary to bounded recursive languages. The unconstrained fragment counts by the same size fixpoint `mu` uses; equality constraints are the hard part, since they correlate children and make an edge's count the size of an intersection.
+ Recursive grouped generators: a recursive `Grouped` is a system of equations over a key set discovered by fixpoint, which is what a recursively typed expression language needs. It shares a prerequisite with retaining one ECTA term per recursive member, so `groupBy`, `match`, `pmf`, and `countBy` can cross the recursive boundary.
+ Term-level shrink rewrites validated by nodeRepresents against the support: propose subtree replacements from the support's own edges and let the automaton check acceptance, complementing the delivered size-ordered minimal search.
